The built-in starter list is only a handful of domains. Full coverage comes from the lists uBlock Origin enables by default: EasyList, EasyPrivacy, Peter Lowe, and the uBlock ads, privacy, badware, quick-fix, and unbreak lists. From this project, run npm run compile-filters and then npm run build, then reload the extension on chrome://extensions. A longer list will not remove a YouTube ad that uses the same address as the video. A page script strips that ad schedule from the player and skips an ad if one still starts. Pause youtube.com, or turn blocking off, to stop the page script.
